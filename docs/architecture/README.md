# Arquitectura — NEXUS DevSuite

Este directorio está reservado para documentación de **arquitectura** del sistema (cuando se formalice).

---

## Relación con el flujo de auditorías

El backlog de desarrollo puede derivarse de **auditorías funcionales** del PO (véase `docs/process/WORKFLOW_DESARROLLO_AUDITORIA.md`). Los **tickets derivados de la auditoría deben implementarse sin modificar la arquitectura existente**: se conectan endpoints, se completan flujos y se añaden vistas o controles dentro del patrón actual. Cualquier cambio que afecte a la arquitectura debe ser validado por SYSTEM ARCHITECT.
