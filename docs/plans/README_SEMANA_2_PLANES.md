## Cómo usar los planes

1. **El día correspondiente:** Abre el archivo del plan según la fecha (ej. 11-03-2026 → PLAN_ETAPA_20_11-03-2026.md).
2. **Sigue los pasos en orden:** Cada plan tiene pasos 1–5 o 1–6 con responsables (PO MASTER, SYSTEM ARCHITECT, MASTER DEVELOPER, QA ENGINEER).
3. **Marca las actividades:** Usa las tablas de actividades y los checklists al final de cada plan para ir tachando lo completado.
4. **Cierre:** Al terminar el día, cumplir el Paso final de “PO MASTER audita cierre” y actualizar docs/CHECKLIST_ETAPAS_PROYECTO.md.
