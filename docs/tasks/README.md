# Tareas del proyecto — NEXUS DevSuite

**Propósito:** Carpeta para archivos de listado de tareas (por sprint, módulo o iniciativa). Cualquier modificación a un archivo en esta carpeta debe registrarse en `docs/project-logs/checklist-change-log.md`.

**Ejemplos de uso:** `api-tasks.md`, `sprint-01-tasks.md`, `migraciones-tasks.md`. Las tareas también pueden estar referenciadas en planes en `docs/` (PLAN_ETAPA_*.md) y en el checklist maestro `docs/CHECKLIST_ETAPAS_PROYECTO.md`.

**Trazabilidad:** Ver `docs/project-logs/README.md` para el procedimiento de registro de cambios y formato de reporte diario.
