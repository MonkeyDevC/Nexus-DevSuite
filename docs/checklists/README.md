# Checklists del proyecto — NEXUS DevSuite

**Propósito:** Carpeta para archivos de checklist de seguimiento (por módulo, etapa o área). Cualquier modificación a un archivo en esta carpeta debe registrarse en `docs/project-logs/checklist-change-log.md`.

**Checklist principal del proyecto:** El documento maestro de etapas y seguimiento está en `docs/CHECKLIST_ETAPAS_PROYECTO.md`. Los checklists específicos (por backend, API, frontend, etc.) pueden ubicarse aquí si se desea separar por área.

**Convención:** Usar nombres descriptivos, por ejemplo `backend-checklist.md`, `api-tasks.md`, `frontend-ux-checklist.md`.

**Trazabilidad:** Ver `docs/project-logs/README.md` para el procedimiento de registro de cambios.
